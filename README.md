# ВЫХОД (VYKHOD) — экстракшен-шутер от первого лица

Unity 6 (6000.0.x), Built-in Render Pipeline, Netcode for GameObjects (хост + подключение по IP).
Windows и macOS (Metal, Apple Silicon + Intel). Все ассеты — бесплатные CC0 из интернета (Kenney, Quaternius, Poly Haven, Google Fonts),
карты РТУ МИРЭА и центра Донецка построены по реальным данным OpenStreetMap.

## Быстрый старт
1. Данные игры: `python -I Tools/gen_data.py` (уже сгенерированы в `Assets/Resources/Data/*.json`).
2. Ассеты: `python -I Tools/fetch_assets.py` — скачивает CC0-пакеты в `Assets/Resources/Imported/`. Без них игра работает на плейсхолдерах.
3. OSM-карты: `python -I Tools/fetch_osm.py` — кладёт `mirea.json` и `donetsk.json` в `Assets/StreamingAssets/Maps/`. Без них эти карты строятся процедурно.
4. Unity Hub → Add → папка проекта → открыть редактором 6000.0.85f1 (или другим Unity 6).
   При первом открытии скрипт `Vykhod/Setup Project` сам создаст сетевые префабы, сцену `Assets/_Game/Scenes/Main.unity` и настройки.
5. Открыть `Main.unity`, нажать Play. Главное меню → Новая игра → убежище → «В РЕЙД».

## Важно про путь проекта
Если в пути проекта есть кириллица (например имя пользователя «я»), Unity из командной строки может не привязать скрипты к префабам.
Для сборок из консоли создана ASCII-ссылка `C:\Users\Public\Vykhod` → папка проекта (`mklink /J`); в Hub можно открывать любой из двух путей, но не оба одновременно.

## Сборка
Меню **Vykhod → Build → Windows x64** или **macOS (Apple Silicon + Intel)**. Сборки падают в `Builds/`.
Для Mac нужен модуль «Mac Build Support (Mono)» в Unity Hub (ставится автоматически скриптом установки).

## Мультиплеер
- Хост: в убежище выбрать карту и режим, «НАЧАТЬ РЕЙД». Хост = сервер + игрок.
- Друзья: главное меню → «Подключиться к другу» → IP хоста (порт 7777). Подключаться можно в любой момент рейда.
- Режимы: **Кооператив** (один отряд, нет дружественного огня) и **PvP: все против всех** (плюс боты). Боты и лут считаются на хосте.
- Через интернет: белый IP + проброс порта 7777 UDP, либо Radmin VPN / Hamachi / ZeroTier.

## Управление
WASD — движение, Shift — бег, Ctrl/C — присед, Space — прыжок, Q/E — наклон, ЛКМ — огонь, ПКМ — прицел, R — перезарядка,
B — режим огня, T — тип патронов, G — граната, 5 — аптечка, 6 — еда, N — ПНВ, L — фонарь, 1–4 — оружие, F — взаимодействие (держать для осмотра),
Tab — инвентарь, Enter — чат, Esc — пауза.

## Что внутри
- 78 стволов (пистолеты, ПП, дробовики, штурмовые, DMR, снайперские, пулемёты, холодное), 125 модулей (дульные, прицелы 1–25x, рукоятки, приклады, цевья, стволы, магазины, ЛЦУ, сошки), 68 типов патронов.
- 153 предмета: медицина с частями тела (кровотечения, переломы, хирургия), еда, ценности, ключи, броня классов 2–6, шлемы, рюкзаки, разгрузки, гранаты, контейнеры.
- 69 заданий у 6 торговцев с цепочками, 26 навыков (качаются действиями, рубежи каждые 10 уровней), 72 перка в 6 ветках, 12 модулей убежища, крафт, ферма, страховка, мастерство оружия.
- 6 карт: РТУ МИРЭА (OSM), Донецк. Центр (OSM), Завод «Прогресс», Посёлок Сосновка, ТЦ «Орбита» (3 этажа), Подземка. У каждой — несколько выходов (с условиями: ключ, деньги, только вдвоём), запертые комнаты, босс со свитой, снайперы на крышах, день/ночь.
- Боты: патруль, слух, зрение, укрытие, бегство, перезарядка; боссы с охраной; ночные.

## Визуал
- Интерфейс в ярком аркадном стиле: главное меню с одной кнопкой «Играть», лобби с панелью разделов слева, действия с предметами через всплывающие окна (`Assets/_Game/Scripts/UI`).
- Карты: CC0-текстуры ambientCG (трава, асфальт, бетон, кирпич, фасады с окнами, крыши, плитка) через триплaнарный шейдер `Assets/Resources/Shaders/Triplanar.shader`, здания и пропсы из паков Kenney, слой укрытий `MapDetails.cs` (бетонные блоки, мешки с песком, ящики, бочки, машины, контейнеры, остановки, киоски, заборы, кусты).
- Автоскриншоты: `VYKHOD.exe -shots <папка>` снимает меню, вкладки лобби, HUD, инвентарь и четыре карты.

## Структура
- `Tools/gen_data.py` — весь контент таблицами (добавил строку → появилось в игре).
- `Assets/_Game/Scripts/Core` — данные, инвентарь, профиль, статы, квесты, торговля, убежище.
- `Assets/_Game/Scripts/Net` — сеть (NetGame, RaidSession).
- `Assets/_Game/Scripts/World` — генерация карт (OSM + процедурные), лут, выходы, двери.
- `Assets/_Game/Scripts/AI` — боты и спавн.
- `Assets/_Game/Scripts/Player` — контроллер, оружие, здоровье, взаимодействие, эффекты.
- `Assets/_Game/Scripts/UI` — весь интерфейс строится из кода (uGUI).
- `Assets/_Game/Scripts/Editor` — автонастройка проекта и сборка.

## Оптимизация под macOS/Metal
Статический батчинг карт, GPU-инстансинг материалов, ограниченные тени (3 уровня качества), не более ~50 точечных источников, NavMesh крупными вокселями,
без постобработки и realtime GI. На ноутбуках ставьте качество 1 в настройках.
